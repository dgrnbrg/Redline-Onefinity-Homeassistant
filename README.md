# Redline CNC (RTS-X) — Home Assistant / HACS Integration

> [!WARNING]
> **Warning: This is AI slop.** This integration and protocol documentation were reverse-engineered and generated by an AI coding assistant. Review the code carefully and use at your own risk—especially when automating power tools, dust collection, or CNC peripherals.

A Home Assistant custom integration (HACS-compatible) for the **Redline CNC / RealTime CNC RTS-X Controller**.

It connects via local push WebSocket (`ws://<host>:8080`) to stream real-time machine state, job progress, coordinates, live camera feed, and I/O states (Spindle, Vacuum / Flood `M8`, Air Assist / Mist `M7`, and Aux Outputs `M62`–`M65`).

See [PROTOCOL.md](PROTOCOL.md) for the complete reverse-engineered WebSocket protocol specification.

## Features & Entities

### Sensors (`sensor`)
* **Machine State** (`sensor.redline_cnc_machine_state`): `"Ready"`, `"Running"`, `"E-Stop"`, `"Disconnected"`, etc.
* **Job Progress** (`sensor.redline_cnc_job_progress`): `0.0%` – `100.0%` (with attributes `current_line`, `total_lines`).
* **Current File** (`sensor.redline_cnc_current_file`): Currently loaded `.ngc` file name (with `file_info`, `full_path`, `total_files_on_controller`).
* **Current Line** (`sensor.redline_cnc_current_line`): Current G-code line number (`int`).
* **Total Lines** (`sensor.redline_cnc_total_lines`): Total G-code lines in the loaded file (`int`).
* **ETA** (`sensor.redline_cnc_eta`): Timestamp (`SensorDeviceClass.TIMESTAMP`) computed from the CNC controller's `elapsed_eta` duration when a job is loaded, rendered as a future countdown timer in Home Assistant without constant ticking.
* **Work Position X / Y / Z / A** (`sensor.redline_cnc_work_position_x`, etc.): Work coordinates (`WPos = MPos - WCS`), scaled to `"in"` or `"mm"` *(disabled by default)*.
* **Machine Position X / Y / Z / A** (`sensor.redline_cnc_machine_position_x`, etc.): Raw machine coordinates (`MPos`) *(disabled by default)*.
* **Target Spindle Speed** (`sensor.redline_cnc_target_spindle_speed`): Commanded spindle speed in `rpm`.
* **Target Feed Rate** (`sensor.redline_cnc_target_feed_rate`): Commanded feed rate (`in/min` or `mm/min`).
* **Active Tool** (`sensor.redline_cnc_active_tool`): Active tool number and description from the controller's tool table.
* **Coordinate Units** & **RTS-X Version**: Diagnostic sensors.

### Binary Sensors (`binary_sensor`)
* **Controller Connected** (`binary_sensor.redline_cnc_controller_connected`): WebSocket connectivity status.
* **Controller Patch Installed** (`binary_sensor.redline_cnc_controller_patch_installed`): `on` when the in-process FastAPI extension (`redline_ha_ext.py`) is active on the controller.
* **Job Running** (`binary_sensor.redline_cnc_job_running`): `on` whenever the machine is actively running a job.
* **E-Stop Active** (`binary_sensor.redline_cnc_e_stop_active`): `on` when the controller is in Emergency Stop.
* **Tool Change Active** (`binary_sensor.redline_cnc_tool_change_active`): `on` when a manual tool change (`M6`) or tool probing routine is active.
* **Spindle Warmup Active** (`binary_sensor.redline_cnc_spindle_warmup_active`): `on` while the 5-stage Spindle Warmup routine (`8000` -> `12000` -> `16000` -> `20000` -> `24000` RPM) is running, with `stage`, `remaining_seconds`, and `status` attributes.
* **Macro Running** (`binary_sensor.redline_cnc_macro_running`): `on` while a user macro is actively executing.
* **IO Spindle** (`binary_sensor.redline_cnc_io_spindle`): `on` when spindle (`M3`/`M4`) is active during a job (or reported directly via WebSocket).
* **IO Vacuum / Flood Coolant (M8)** (`binary_sensor.redline_cnc_io_vacuum_flood_coolant_m8`): `on` when `M8` (or direct `vacuum`/`flood` IO) is active, including automatic state preservation across `M6` manual tool changes.
* **IO Air Assist / Mist Coolant (M7)** (`binary_sensor.redline_cnc_io_air_assist_mist_coolant_m7`): `on` when `M7` (or direct `air_assist`/`mist` IO) is active.
* **IO Aux Output P0–P3 (OUT0–OUT3)** (`binary_sensor.redline_cnc_io_aux_output_p0_out0`, etc.): Digital output pin states (read directly from hardware GPIO when the controller patch is installed, or inferred from `M62`–`M65` G-code).

### Switches (`switch`)
* **Output 0 (OUT0) – Output 3 (OUT3)** (`switch.redline_cnc_output_0_out0` .. `switch.redline_cnc_output_3_out3`): Turn the 4 hardware auxiliary outputs (`OUT0`–`OUT3`) on or off directly via `controller.comm.setOutput(pin, state)`, automatically adopting any custom output labels configured in the RTS-X UI.

### Camera (`camera`)
* **Camera Feed** (`camera.redline_cnc_camera_feed`): Live `640x480` MJPEG stream and still snapshots decoded on-demand from the controller's WebSocket `image_data` stream.

### Buttons (`button`)
* **Refresh Status** (`button.redline_cnc_refresh_status`): Forces an immediate refresh of status, version, tool table, file tree, and HA extension state.
* **Install Controller Patch** (`button.redline_cnc_install_controller_patch`): 1-click SSH installer that backs up `Web_API.py` to `/home/rtcnc/redline_ha_backups/`, initializes a Git repository in `/home/rtcnc/rtcnc/RTS1/_internal`, writes a read-only `Web_API.py.orig` + `.sha256` digest, deploys `redline_ha_ext.py`, and automatically restarts RTS1 (with motion/spindle safety checks) to load the patch immediately.
* **Uninstall Controller Patch** (`button.redline_cnc_uninstall_controller_patch`): 1-click SSH uninstaller that restores the exact vendor `Web_API.py` via surgical marker strip verified against SHA-256 and Git, removes `redline_ha_ext.py`, and restarts RTS1 back into clean factory state.
* **Start Spindle Warmup** & **Cancel Spindle Warmup**: Launch or abort the native 5-stage HMI Spindle Warmup sequence (requires enabling "Allow remote spindle warmup and macro execution" in integration options).
* **Macro 1 – Macro 12** & **Abort Macro**: Trigger any of the 12 configured controller macros when the machine is `Ready`/`IDLE`, or abort an active macro (disabled by default; enable the desired slots in entity settings and enable remote motion in integration options).

### Services (`redline_cnc.*`)
* `redline_cnc.run_macro`: Execute a configured macro by name (e.g. `"Park"`) or slot number (`1`–`12`).
* `redline_cnc.abort_macro`: Abort an actively running macro.
* `redline_cnc.set_output`: Set hardware output pin `0`–`3` (`OUT0`–`OUT3`) to `true` or `false`.
* `redline_cnc.start_spindle_warmup` / `redline_cnc.cancel_spindle_warmup`: Start or cancel the 5-stage Spindle Warmup routine.
* `redline_cnc.install_patch` / `redline_cnc.uninstall_patch`: Install or uninstall the controller FastAPI extension over SSH.
* `redline_cnc.restart_rts1`: Safely restart the RTS1 controller process over SSH (`force`: false by default).

## Installation

### Option 1: HACS (Recommended)
1. Open **HACS** in Home Assistant -> **Integrations** -> top-right menu (`⋮`) -> **Custom repositories**.
2. Add this repository URL with category **Integration**.
3. Click **Download** on **Redline CNC (RTS-X)** and restart Home Assistant.
4. Go to **Settings** -> **Devices & Services** -> **Add Integration** -> search for **Redline CNC (RTS-X)**.
5. Enter your controller host and WebSocket port (`8080`).

### Option 2: Manual Installation
1. Copy the `custom_components/redline_cnc` directory into your Home Assistant `<config>/custom_components/` directory.
2. Restart Home Assistant and add **Redline CNC (RTS-X)** from **Settings** -> **Devices & Services**.

## Example Home Assistant Automation (Shop Vacuum)

```yaml
automation:
  - alias: "CNC Shop Vacuum Auto Control"
    description: "Turn on shop vac with M8 vacuum sensor, turn off 15s after M9/stop"
    mode: restart
    trigger:
      - platform: state
        entity_id: binary_sensor.redline_cnc_io_vacuum_flood_coolant_m8
        to: "on"
        id: "turn_on"
      - platform: state
        entity_id: binary_sensor.redline_cnc_io_vacuum_flood_coolant_m8
        to: "off"
        for: "00:00:15"
        id: "turn_off"
    action:
      - service: "switch.{{ trigger.id }}"
        target:
          entity_id: switch.shop_vacuum
```
